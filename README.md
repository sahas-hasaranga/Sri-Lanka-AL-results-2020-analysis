# 📊 Sri Lanka G.C.E. A/L (2020) Data Analysis

This project performs Exploratory Data Analysis (EDA) and data profiling on the Sri Lankan G.C.E. Advanced Level 2020 examination results dataset.

## 📌 Project Overview
The dataset contains **337,553 records** and **19 features** including student streams, Z-scores, district ranks, subjects, and results. 

Here is a quick summary of the dataset:
![Data Summary](Screenshot%202026-08-24%20104822.png)

## 📁 Files in this Repository
* `al_data_analysis.ipynb` - The Jupyter Notebook containing the Python code for loading and summarizing the data.
* `profiling_report.html` - An in-depth HTML data profiling report generated using Sweetviz.
